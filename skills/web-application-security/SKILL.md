---
If you are reviewing a web application, you should focus on the following kinds of vulnerabilities:

- Injection flaws (SQL, NoSQL, Command etc.)
- Authentication and session management weaknesses
- Broken access control and authorization bypasses
- Security misconfigurations
- Sensitive data exposure
- Insecure deserialization
- Server-Side Request Forgery (SSRF)
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Race conditions and time-of-check-time-of-use (TOCTOU) issues
- Cryptographic failures and weak implementations
- Business logic vulnerabilities
